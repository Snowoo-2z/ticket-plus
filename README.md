# ticket-plus

## Installation

```bash
npm install
npm run build
npm start
```

Renseigner `.env`, puis activer `Message Content Intent` dans le portail Discord.

Pour enregistrer immédiatement les commandes sur un serveur de test, renseigner `DISCORD_GUILD_ID`.

## Commandes

- `/ticket-categorie-config`
- `/panel-ticket`

## Variables du message d’accueil

- `{user}`
- `{ticket}`
- `{number}`
